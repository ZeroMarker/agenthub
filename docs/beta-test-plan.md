# AgentHub Beta 验证计划

> 目标：邀请 3–5 名真实用户，在不需要开发者现场操作的情况下完成安装、查询、升级和卸载。

## 测试前准备

- 使用已发布的版本，不使用 `cargo run` 或开发目录。
- 为每位参与者提供校验和、安装说明和反馈表。
- 至少覆盖 Windows、macOS、Linux 中的两个平台。
- 记录 CLI 与 GUI 的结果；不要收集 API key 或会话内容。

## 用户任务

1. 安装 AgentHub。
2. 查询 Agent 列表、详情并搜索一个 Agent。
3. 使用 `--dry-run` 预览安装命令。
4. 安装一个可用的 CLI 或桌面 Agent。
5. 查看安装状态和版本。
6. 执行一次升级或重复安装。
7. 卸载该 Agent。
8. 确认 AgentHub 和目标 Agent 均没有异常残留。
9. 在 GUI 中重复查询和至少一个安装管理操作。

## 记录指标

- 每项任务是否独立完成。
- 首次成功耗时和需要帮助的步骤。
- 错误信息是否能说明原因和下一步。
- `dry-run` 是否修改了系统。
- 安装失败、取消、升级和卸载后的状态是否准确。
- CLI 与 GUI 的结果是否一致。
- 用户主观评分和最困惑的界面。

## 退出标准

- 3–5 名用户全部完成查询流程。
- 核心安装/卸载任务成功率至少 90%。
- 没有“失败却显示成功”或“未安装却显示已安装”的问题。
- 所有 P0/P1 问题关闭或有明确发布阻断结论。
- 反馈和环境矩阵归档到 issue/release 文档中。

该计划需要真实参与者和目标平台，无法由自动化测试替代；完成后再勾选 `todo.md` 中的 Beta 项。
